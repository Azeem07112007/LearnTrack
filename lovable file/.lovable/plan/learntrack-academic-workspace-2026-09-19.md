# LearnTrack academic workspace

## Goal
Recreate the six supplied LearnTrack screens as one responsive, interactive academic portal.

## Screens
- Sign-in screen at `/login`
- Student dashboard at `/`
- Curriculum map at `/map`
- Academic leaderboard at `/leaderboard`
- Quiz and examination workspace at `/quiz`
- Course assignments at `/assignments`

## Build approach
- Create a shared fixed sidebar and top toolbar matching the references.
- Reproduce the dense academic cards, tables, status badges, progress bars, and screen-specific layouts.
- Make navigation, student/teacher switch, quiz answers, question controls, filters, pagination, assignment selection, and sign-in interactions functional in the browser.
- Adapt the layout for phones and tablets with a compact navigation bar and stacked content.
- Use the supplied avatar image URL and Material Symbols font referenced by the HTML.

## Design system
- Preserve the reference’s white and pale-lavender surfaces, strong academic blue, emerald verification states, compact serif headings, and dense sans-serif labels.
- Define all color, spacing, typography, and elevation roles as shared semantic tokens.

## Validation
- Check every route at desktop and mobile sizes.
- Verify navigation and key controls visually and confirm the preview builds without errors.
